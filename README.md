# [Pixel Art](https://lucjoon.github.io/pixel-art/index.html)

Éditeur de pixels 64×64 — dessine des sprites en noir et blanc, exporte-les en BMP.

Clique sur **[Pixel Art](https://lucjoon.github.io/pixel-art/index.html)** pour ouvrir l’application.

## Développement local

```bash
git clone https://github.com/lucjoon/pixel-art.git
cd pixel-art
open index.html
```

Si la page en ligne ne s’affiche pas : *Settings → Pages → Branch `main` / root*.
