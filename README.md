# Éditeur de pixels 64×64

Dessine des sprites en noir et blanc, exporte-les en BMP.

## Ouvrir l’éditeur

**[→ Lancer l’éditeur](https://lucjoon.github.io/pixel-art/)**

*(GitHub Pages — fichier `index.html` à la racine du dépôt.)*

Si la page ne s’affiche pas encore, active **Pages** dans les paramètres du dépôt : *Settings → Pages → Branch `main` / folder root*.

## Développement local

Clone le dépôt, puis ouvre `index.html` dans ton navigateur :

```bash
git clone https://github.com/lucjoon/pixel-art.git
cd pixel-art
open index.html
```
